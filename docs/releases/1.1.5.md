# Xsl3 1.1.5 candidate

Unreleased. This candidate contains the bounded P7G copied-attribute identity corrections.
Release tagging and publication remain a separate step.

## Changes

DTD-declared `ID`, `IDREF` and `IDREFS` attributes now retain their identity properties when loaded
through XDM/XSLT 2.0+ readers, copied into an `attribute()*` variable and inserted into a new document.
Both `validation="preserve"` and `validation="strip"` keep those properties. Input with ATTLIST-only
declarations and readers already positioned past the DOCTYPE receive the same treatment. Experimental
forward execution carries the DTD declarations into copied and grounded nodes.

The corrections distinguish identity from schema type annotations: stripping annotations must not
strip identity. Detached attributes remain parentless and distinct, keep their names/values, and
remain usable after the source reader closes. `xml:id` normalization and borrowed-reader ownership
are preserved. XSLT 1.0 and direct stock-compatible compact loading retain their existing policy.

There is no public API or saved-format change. P7F's optimization for ordinary untyped attributes is
retained. New normal/debug saved consumers exercise all six contracts on .NET 8, .NET 10 and NativeAOT.
See the [bounded plan](../plan/p7g-attribute-identity-contracts.md) for completion criteria.

## Verification

All six contracts pass **330 / 234** managed regression rows on .NET 10 / .NET 8 in Release and
Debug. Full managed units pass **4,040 / 3,783** in each configuration; upstream, differential,
ordinary conformance and reviewed S1/S2 checks pass with existing raw failure inventories retained.
The 24 saved styles pass **192** checks on each managed framework and macOS ARM64 NativeAOT,
including actual execution-mode verification and a missing-case negative control.

The three-size allocation comparison against 1.1.4 passes all **18** fresh processes at 10 MiB,
200 MiB and 2 GiB, retaining the P7F gain. The unchanged ordinary three-round performance gate passes
with time geometric mean **0.970** and maximum allocation ratio **1.001139**. These are workload-specific
measurements; they do not establish supported streaming or memory-budget acceptance.

See the [close-out](../p7g-attribute-identity-2026-10-29.md), [exact snapshot](../plan/p7g-results.json)
and [PR #25 checks](https://github.com/skuirrels/Xsl3/pull/25/checks).

## Boundaries

Streaming remains unsupported, normal execution remains tree-based and `supports-streaming` remains
`no`. Startup footprint, the 20 MiB memory target, new streaming constructs and broader schema work
are excluded. The pre-existing Debug compiler line-information finding is [deferred](../plan/p7g-deferred.md).

When this candidate is released, update `Xsl3`, `Xsl3.Build` and `Xsl3.Cli` together to 1.1.5 and
regenerate saved stylesheets with matching compiler/runtime packages. The published version remains
1.1.4 until NuGet and GitHub publication have both been verified.

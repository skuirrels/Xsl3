# Xsl3 1.1.4

Release date: 29 October 2026. This patch closes the bounded P7F attribute-copy allocation phase and
includes P7E's diagnostic tooling and audit. It does not claim supported streaming.

## Changes

Ordinary untyped native attribute copies now use a minimal compact fragment instead of allocating a
general tree builder and unused child buffers. Each copy retains independent parentless node identity,
its name and value. Typed, DTD identity-sensitive and `xml:id` attributes retain their existing copy
policies. No public API or saved-format change is introduced.

In the measured identity workload, transformation allocation falls **23.55%** at each of the original
10 MiB, 200 MiB and 2 GiB input sizes on Linux x64 and macOS ARM64. Separate uninstrumented median
timings improve **4.53–7.21%**. All **72** comparison processes consume the full input and validate
independent output fingerprints. These results apply to that workload; cumulative allocation is not
retained memory or whole-process RSS.

P7E's source-frozen 1.1.3 audit, original failed cohorts, paired diagnostics and measurement safeguards
are included. Scheduled/default memory limits and canonical workloads remain unchanged. P7D validation
contracts and P7C source-reader boundary corrections remain included.

See the [P7F close-out](https://github.com/skuirrels/Xsl3/blob/v1.1.4/docs/p7f-identity-allocation-2026-10-29.md)
and [exact result snapshot](https://github.com/skuirrels/Xsl3/blob/v1.1.4/docs/plan/p7f-results.json)
for raw evidence provenance, exact medians and limitations.

## Upgrading

Update all three packages together:

```sh
dotnet add package Xsl3 --version 1.1.4
dotnet add package Xsl3.Build --version 1.1.4
dotnet tool update --global Xsl3.Cli --version 1.1.4
```

The packages support .NET 8 and .NET 10. Compiling saved stylesheets requires the .NET 10 SDK;
saved stylesheets also run under NativeAOT. Runtime compilation requires dynamic code.
Regenerate saved stylesheets with matching compiler/runtime packages. Existing saved formats remain
supported; no new public helper signature or format is introduced by P7F.

## Remaining limits

Streaming remains unsupported, normal execution remains tree-based and `supports-streaming` remains `no`.
Both complete 2 GiB / 200 MiB memory matrices pass **16/16**. The original 200 MiB / 20 MiB matrix
remains **0/16** on Linux and records **12/16** on macOS, versus the retained P7E macOS **13/16**.
The additional accumulator outer-RSS failure is retained alongside three passing paired repeats;
those repeats do not replace the original failed matrix or relax the limit.

The unrelated DTD identity roundtrip finding is
[deferred](https://github.com/skuirrels/Xsl3/blob/v1.1.4/docs/plan/p7f-deferred.md) to its own contract investigation.
Startup footprint, other allocation hotspots and full P7 memory/throughput acceptance remain separate work.

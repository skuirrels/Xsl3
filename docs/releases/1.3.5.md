# Xsl3 1.3.5

This documentation release records the Phase 7 Linux profiles and the November acceptance results.
Both original memory matrices passed. Identity, source-document, and fork still exceed the
original 100 MB throughput limit. Streaming remains experimental and opt-in. Tree execution is
the default and `supports-streaming` is `no`. [Phase 7 handoff](https://github.com/skuirrels/Xsl3/blob/v1.3.5/docs/plan/p7-handoff.md)

Update `Xsl3`, `Xsl3.Build` and `Xsl3.Cli` together and regenerate saved stylesheets with matching
packages. The library has `net8.0` and `net10.0` assets. On a .NET 11-only installation, set
`DOTNET_ROLL_FORWARD=LatestMajor` when running the CLI or building with `Xsl3.Build`.

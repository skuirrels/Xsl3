# Xsl3 1.1.6

Release date: 29 October 2026. This patch closes the bounded P7H Debug compiler source-line contracts.

## Changes

Repeated bare-variable sequences such as `xsl:sequence select="$value"` now receive distinct
instruction nodes before source-line metadata is attached. The variable keeps its original binding
and initializer location; each use keeps its own sequence point. This removes the Debug compiler's
"Attempt to override SourceLineInfo in debug mode" assertion without suppressing that check.

The correction uses the existing XSLT 1.0 compiler's reference-wrapper pattern at the instruction
source-location boundary. It does not clone or re-evaluate the variable. No public API, saved-format,
DTD identity, annotation policy or runtime feature claim changes.

The original six P7G contracts retain their inputs and expected results. A separate fixture variant
restores `$second` instead of `$second/self::attribute()`. Both remain covered, including initial
and positioned readers, both DTD forms, both public source APIs and grounded/forward execution.

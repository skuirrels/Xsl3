# 1.1.3: P7D schema-validation contracts

Version 1.1.3 closes the bounded six-case [P7D phase](../plan/p7d-validation-contracts.md).
Normal execution remains tree-based; streaming remains experimental and unsupported, and
`system-property('xsl:supports-streaming')` remains `no`.

## Changes

- With `XsltSettings.SchemaAware=false`, treat `validation="lax"` as stripping annotations rather than
  rejecting the stylesheet with `XTSE1660`. Both public APIs and saved stylesheets support the corrected
  contract for source and result documents.
- Apply an explicit strip policy to grounded source documents, including basic lax/preserve
  normalization. Inputs from validating readers become untyped as requested. Experimental forward
  execution retains the same annotation policy and borrowed-reader ownership.
- Apply whitespace rules after stripping annotations and initialize filtering through the shared
  scoped view for positioned 2.0+ readers. Retain `xml:space`, namespace bindings, IDs/IDREFs and
  document URIs; keep the legacy 1.0 path unchanged.
- Document the distinction between schema-aware lax validation (`xs:anyType` without declarations),
  basic stripping (`xs:untyped`), supplied annotations and explicit imports for strict validation.

The three original lax fixtures pass in basic mode after failing with `XTSE1660` on the independently
rebuilt 1.1.2 runtime. All six raw schema-aware outcomes remain visible with
[individual dispositions](../plan/p7d-validation-cases.csv); no official fixture, expectation or existing
baseline is changed. No public API, helper signature or saved-format change is introduced.

## Upgrading

Update all three packages together:

```sh
dotnet add package Xsl3 --version 1.1.3
dotnet add package Xsl3.Build --version 1.1.3
dotnet tool update --global Xsl3.Cli --version 1.1.3
```

The packages support .NET 8 and .NET 10. Compiling saved stylesheets with Xsl3.Build requires the
.NET 10 SDK; saved stylesheets also run under NativeAOT. Runtime compilation requires dynamic code.
Regenerate affected saved stylesheets with
matching compiler/runtime versions. Regeneration is required to compile the corrected grounded strip
path; previously emitted code is not rewritten by a runtime update. Existing saved formats remain supported.

The schema-aware setting remains opt-in. Strict validation in basic mode still raises `XTSE1660`.
`XsltSettings.Schemas` remains an import catalog; it does not implicitly import declarations for explicit
strict validation. Preserving an already validated reader's annotations does not require that import.
See the [migration guide](../migration.md).

## Deferred scope

General streaming runtime bounds, the original 20 MiB memory target, throughput acceptance, new streaming
constructs, XSD 1.1 and public API expansion remain deferred. P7D does not reopen P7C or complete full P7.

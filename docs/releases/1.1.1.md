# 1.1.1: P7B analysis close-out

Version 1.1.1 closes **P7B**, the bounded streamability-analysis follow-up to the 1.1.0 foundations.
Normal execution remains tree-based. Streaming remains experimental and unsupported;
`system-property('xsl:supports-streaming')` continues to return `no`.

## Changes

- Apply XSLT 3.0 §3.9.1 to instructions processed with XSLT 1.0 behavior inside declared-streamable content.
  Strict analysis now rejects these with `XTSE3430`, even when their bodies are motionless.
- Preserve source streamability diagnostics before lowering rejected units. Debug `xsl:number` validation
  and Explain recompilation report the static errors rather than masking them with lowering failures.
- Keep the developer tool's `qil` and `qilopt` diagnostics when a rejected compilation produces no QIL;
  these commands exit with failure and emit no QIL.
- Complete the owner-approved reviewed fixtures with independent specification-based expectations,
  canonical-input-derived positive results, complete expression mappings, integrity checks and separate CI reports.
  Reviewed S2 requires the primary structured static code, source location and reason, or a checked positive XML result.

## Upgrading

Update `Xsl3`, `Xsl3.Build` and `Xsl3.Cli` together to **1.1.1**. Regenerate saved stylesheets with matching
compiler/runtime packages. This patch adds no public API or saved-assembly format changes. Runtime compilation
still requires dynamic code; NativeAOT consumers use saved stylesheets.

```sh
dotnet add package Xsl3 --version 1.1.1
dotnet add package Xsl3.Build --version 1.1.1
dotnet tool update --global Xsl3.Cli --version 1.1.1
```

Stylesheets relying on a `version="1.0"` instruction inside a declared-streamable mode or source-document
may now receive `XTSE3430`. Remove the streamability declaration when tree execution is intended, explicitly
select Fallback, or update the instruction version when the 2.0/3.0 semantics are appropriate:

```csharp
var settings = new XsltSettings
{
    Streamability = XsltStreamabilityMode.Fallback
};
```

Fallback controls the analysis policy and permits ordinary tree execution. Ordinary non-streamable
backwards-compatible behavior is retained. See the [migration guide](../migration.md).

## Deferred scope

Full-P7 runtime completion, general retained-model bounds, the 20 MiB absolute memory target and streaming
throughput acceptance remain deferred. Their unchanged experimental checks are separate from supported release
CI. P7B completion makes no supported streaming, memory-budget or universal performance claim.

# Xsl3 1.1.7

Release date: 1 November 2026. This release closes a bounded P7 runtime correctness and allocation checkpoint.
Full streaming remains experimental and unsupported.

## Changes

- Correct copied accumulator applicability and phase provenance, including schema-created text and
  `copy-accumulators` with stripped types. Preserve schema default/fixed text around comments and processing instructions.
- Strengthen fork ownership, immutable headers, independent schema snapshots, cancellation and caller-owned
  input/output. Reduce handoff overhead without changing configured buffers or thread counts.
- Reduce allocation in dynamic calls, accumulator matching, compact-tree value storage and grounded
  adjacent groups. Large tree columns use pages to avoid whole-column resize peaks.
- Preserve canonical streamed atomization, string joining and stripped attribute-copy semantics.
- Reject saved named functions with unavailable name/arity bindings. Keep schema/typed-node saved layouts
  compatible while recording optional accumulator-filter metadata.
- Strengthen physical-read, first-output, lifetime and conformance evidence, with original inputs,
  fingerprints, error codes and memory/throughput targets retained.

Default execution stays tree-based, as in earlier published releases. `XsltSettings.Streamability = Strict`
controls static checking and does not enable experimental forward execution by itself. The development
opt-in remains available for qualification. Saved styles retain their recorded execution mode.
`supports-streaming` remains `no`.

The internal Linux NativeAOT probe uses packed relative relocations and requires LLD/glibc 2.36+.
Consumer libraries, CLI and build packages retain their existing platform requirements.

## Verification and limits

The release gates cover full .NET 8/10 Release/Debug unit suites, upstream and differential tests,
ordinary W3C conformance, NativeAOT and the ordinary performance gate. See
[PR #27 checks](https://github.com/skuirrels/Xsl3/pull/27/checks) for reviewed-source CI.

Coordinated release packages are checked for version/commit metadata, both target frameworks,
package-only managed consumers, saved compilation through Xsl3.Build, CLI/tool execution and NativeAOT.
The [release workflow](https://github.com/skuirrels/Xsl3/actions/workflows/release.yml) builds and tests
the tagged source before the owner's required NuGet deployment review. GitHub and NuGet publication
are verified separately from source merge.

The original experimental streaming RSS and throughput gates are still unmet. This checkpoint does
not advertise general constant-memory streaming or full P7 completion. Isolated optimization experiments
that were not adopted into PR #27 are excluded. See the [checkpoint boundary](../plan/p7-runtime-checkpoint.md)
and [full development evidence](../plan/p7-completion.md).

Update `Xsl3`, `Xsl3.Build` and `Xsl3.Cli` together to **1.1.7** and regenerate saved stylesheets
using matching compiler/runtime packages. The P7H Debug compiler source-line fix remains included.

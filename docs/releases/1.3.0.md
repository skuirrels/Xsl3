# Xsl3 1.3.0

Release date: 4 November 2026. This release names the five extensions that strict streamability analysis
applies to the XSLT 3.0 rules and adds a setting to turn them off. Full streaming remains experimental and
unsupported.

## New setting

`XsltSettings.StreamabilityExtensions` (default `true`) controls five extensions to the §19 analysis that
earlier releases already applied with no way to turn them off:

- `E//N` analysed as `E/descendant::N`, for example `.//x`, `$p//x` and `a[1]//x`;
- a scanning expression that starts with `.`;
- a quantified expression over streamed nodes whose condition is motionless, such as
  `some $x in doc/a satisfies $x/@k = '2'`;
- `S except .`, which stays striding;
- `current-group()` over a grounded selection, which is motionless wherever it is used.

XSLT 3.0 §19.10 allows a processor to extend the streamability rules only when the user asks for it. The
W3C test suite and both streaming processors in the W3C implementation report expect these forms to be
streamable, so the default is unchanged: 101 W3C strict streaming cases depend on them and none expects them
off. Set the property to `false` for the specification's analysis exactly; such constructs then raise
XTSE3430 under the default `Strict` mode, or run unstreamed under `Fallback`.

Nothing changes for existing stylesheets. The [extension review](../plan/p7-extension-review.md) records
the specification text, the W3C cases and the owner decision.

## Verification and limits

W3C strict streaming is unchanged at 2,696 of 2,712 cases (99.41%), and 2,595 with the extensions off.
Full .NET 8 and .NET 10 unit suites, upstream, differential, W3C, NativeAOT and the performance gate run in
[PR #30 checks](https://github.com/skuirrels/Xsl3/pull/30/checks). The
[release workflow](https://github.com/skuirrels/Xsl3/actions/workflows/release.yml) builds and tests the
tagged source before the owner's required NuGet deployment review.

Default execution stays tree-based and `supports-streaming` remains `no`. The original streaming RSS and
throughput gates are still unmet; this release does not claim full P7 completion.

Update `Xsl3`, `Xsl3.Build` and `Xsl3.Cli` together to **1.3.0** and regenerate saved stylesheets
using matching compiler/runtime packages.

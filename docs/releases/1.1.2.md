# 1.1.2: P7C input-boundary correctness

Version 1.1.2 closes **P7C**, the bounded positioned source-reader correctness phase.
Streaming remains experimental and unsupported. Normal execution builds trees and
`system-property('xsl:supports-streaming')` continues to return `no`.

## Changes

- Restrict an `XmlReader` positioned on an element to that subtree during experimental
  `xsl:source-document` execution. Following siblings are excluded. For example, selecting the
  first `doc` in `<outer><doc/><doc><record/></doc></outer>` now reports zero records rather than one.
- Preserve inherited namespace bindings used only in QName values when scoping source and
  initial readers, including transparent reader wrappers. Retain schema annotations and the
  requested preserve/strip/validation policy.
- Keep borrowed readers open at the selected element's boundary after success, early exit or
  a body error, while retaining the existing cleanup policy for owned inputs.
- Retain the complete strict-forward failure inventory in CI. The gate also rejects lost passing
  cases, new or changed skips, and unmatched expected-error codes. It permits genuine fixes
  through the existing failure-baseline review process.

No public API or saved-assembly format changes are introduced. Original W3C fixtures and
P7B raw/reviewed analysis results remain unchanged.

## Upgrading

Update all three packages together and regenerate saved stylesheets with matching compiler/runtime versions:

```sh
dotnet add package Xsl3 --version 1.1.2
dotnet add package Xsl3.Build --version 1.1.2
dotnet tool update --global Xsl3.Cli --version 1.1.2
```

The packages support .NET 8 and .NET 10. Compiling saved stylesheets with Xsl3.Build requires the
.NET 10 SDK; saved stylesheets run on .NET 8 and later and under NativeAOT. Runtime compilation
still requires dynamic code. Existing Strict/Fallback analysis defaults are unchanged.

Resolvers returning positioned readers now expose only their selected element in the experimental
forward path. Code that relied on following siblings being included must explicitly select the
intended input instead. See the [migration guide](../migration.md).

## Deferred scope

Full-P7 runtime completion, general retained-model bounds, the 200 MiB input / 20 MiB absolute
memory target and streaming throughput acceptance remain deferred. This patch does not enable
supported streaming, expand public APIs, alter saved formats, or change benchmark inputs or limits.

See the [changelog](../../CHANGELOG.md), [P7C close-out](../plan/p7c-runtime-correctness.md),
[result snapshot](../plan/p7c-results.json) and [original P7 plan](../plan/p7-streaming.md).

# Xsl3 1.3.4

Xsl3 supports .NET 11 applications. The NuGet library ships `net8.0` and `net10.0` assets, and
NuGet selects the `net10.0` asset for `net11.0` applications.

[PR #45](https://github.com/skuirrels/Xsl3/pull/45) adds Linux and Windows CI checks on an isolated
.NET 11 installation. The checks cover XML runtime bridges, both transformation APIs, saved
stylesheets, CLI transformation and compilation, and the MSBuild stylesheet compiler.

If .NET 11 is your only installed runtime, set `DOTNET_ROLL_FORWARD=LatestMajor` in the
environment when running `xsl3` or building with `Xsl3.Build`. This lets their packaged .NET 10
tools start on .NET 11. Update `Xsl3`, `Xsl3.Build` and `Xsl3.Cli` together to **1.3.4** and
regenerate saved stylesheets with matching packages.

Streaming remains experimental and opt-in. Tree execution is the default and
`supports-streaming` remains `no`. Supported streaming still requires all original
Phase 7 memory and throughput gates.

# Phase 7 experimental runtime checkpoint for 1.3.2

Baseline: `v1.3.1` (`5bd3b07687f80ead5ff4e7586e492b4b08dd0a63`). The candidate ports
only the current-event stack guard and retry contracts from `1ef7c32` to the released
runtime. The differential harness gives both engines the same resolver failure for the
missing-document URI used by the XsltSettings fixtures. This controls the timeout seen
in CI job `127813941325` without depending on external DNS or proxy timing.

The checkpoint has one candidate and at most one corrective iteration. Qualify the exact
release source against these criteria:

- The two reader retry cases and full .NET 8/10 Release and Debug unit suites pass. Hosted
  CI passes all four jobs, including the differential suite.
- On one Linux host, compare the released and candidate engines using the same benchmark
  consumer, canonical 100 MB inputs, and three alternating-order rounds. All 84 outputs
  must match their corresponding canonical fingerprints. Require the slowest candidate
  identity streaming sample to be faster than the fastest baseline identity sample. For
  the other six workloads, require candidate/baseline streaming medians at or below 1.05.
  This uses the existing 5% slowdown tolerance from the allocation comparison as the
  checkpoint regression limit. These criteria are fixed before measurement.
- The original NativeAOT memory gates pass all 32 workload/budget combinations, including
  200 MiB inputs under 20 MiB and 2 GiB inputs under 200 MiB. Preserve the original whole
  process RSS and managed heap limits and output checks.
- Publish GitHub and NuGet 1.3.2 from the same qualified commit after merge. Release notes
  report the measured result and describe forward execution as experimental opt-in with
  `supports-streaming = no`.

The scheduled acceptance jobs retain their original requirements. Full Phase 7 qualification
tracks the original seven throughput targets separately. If this checkpoint still misses a
release gate after the permitted correction, close it with the evidence and hold the release.

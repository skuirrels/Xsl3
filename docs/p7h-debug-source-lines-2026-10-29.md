## Reproduction and correction

The original P7G expression `xsl:sequence select="$second"` fails with the unchanged compiler
when the library is built in Debug and stylesheet debugging is enabled. Of the 288 .NET 10
bare-variable paths, 144 normal-style paths pass and 144 debug-style paths hit
`SetLineInfoCheck`: "Attempt to override SourceLineInfo in debug mode". All 288 pass with
the Release library. Each of the six DTD identity/copy-policy contracts has the same disposition.
The [case inventory](plan/p7h-debug-source-line-cases.csv) records these independently retained results.

A bare variable expression returns a shared `QilIterator`. Attaching an instruction's location
to that reference makes its next use collide with existing metadata; a global variable already
has declaration metadata before its first use. At the point where `CompileInstructions` assigns
an instruction location, the compiler now gives a reference a fresh `Nop` wrapper. Its child remains
the same binding. Declaration/initializer metadata and distinct instruction locations are preserved.
`SetLineInfoCheck` and its assertion are unchanged.

The wrapper belongs at this metadata boundary. Population-selection expressions retain their
existing form, so forward function-path lowering still recognizes its bindings. The full existing
`StreamedFunctionPathTests` matrix is a regression control alongside the new contracts.
No runtime tree/identity path, public API or saved format changes.

## Contracts and focused results

The original P7G fixture and expected results remain the default. A separate `bareVariable` variant
restores `$second` for both reconstructed documents; the original `$second/self::attribute()` variant
continues to run. All 24 original stylesheet inputs are byte-identical to the 1.1.5 package-validation
cohort, and the original P7G CSV inventory is unchanged.

The six cases are DTD ID/IDREF/IDREFS × preserve/strip. Each has 48 passing .NET 10 rows
(32 source and 16 saved) and 32 passing .NET 8 source rows in each library configuration.
These cover both public source APIs, normal/debug styles, grounded/forward execution, both DTD
forms and initial/positioned readers. Both reconstructed-document validation policies and all
P7G identity/name/value/ownership expectations are retained.

Ten additional rows per framework check QIL source-location ownership, a single shared binding,
once-only local/global extension evaluation, and exact executing-instruction error line/module/code
through the text-preserving modern overload and direct legacy reader API. The focused P7H matrix
passes 298 / 202 on .NET 10 / .NET 8. Full units pass 4,342 / 3,989 in both Release and Debug.

The original P7G saved cohort and the bare-variable cohorts generated by Release and Debug compilers
each emit 24 normal/debug grounded/forward styles. Each cohort passes 192 checks on .NET 8,
192 on .NET 10 and 192 on macOS ARM64 NativeAOT: 1,728 total. The generator decodes the actual saved
initial-mode flag with the runtime. Saved consumers enumerate the required contracts independently,
use two distinct token pairs, check reader ownership and retain full globalization with AOT/trim
warnings treated as errors.

Reproduce the P7H saved cohorts with:

```sh
bash eng/verify-attribute-identity.sh osx-arm64 artifacts/p7h-release --bare-variable Release
bash eng/verify-attribute-identity.sh osx-arm64 artifacts/p7h-debug --bare-variable Debug
```

Use a fresh output directory for each invocation. Hosted CI runs the focused Debug matrix on Linux
and Windows and the two additional managed/native saved cohorts on Linux.

## Boundaries

The independent `XsltCompiler.Compile(XmlReader)` source-mapping finding is [deferred](plan/p7h-deferred.md).
The diagnostic controls do not hard-code a line offset. The compiler obtains every location from the
loaded instruction, and tests derive their expected line from the source reader. Fixtures supply
explicit test inputs and never become runtime data sources.

No startup, memory-budget, new construct or broad compiler work is included. Full P7 remains deferred,
streaming remains unsupported, and `supports-streaming` remains `no`. Stop at these contracts and gates;
tagging and publication remain a separate release operation.
